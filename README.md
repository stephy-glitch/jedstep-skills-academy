# Jedstep Skills Academy Website

Official multi-page website for **Jedstep Skills Academy**, Dindigul, Tamil Nadu.

## Pages

- **Home** (`index.html`) – Hero, about preview, programmes highlight, PAPL approach
- **About** (`about.html`) – Full story & “Why Partner With Us”
- **Courses** (`courses.html`) – All programmes
- **Vision & Mission** (`vision.html`) – Mission, Vision, Philosophy
- **Contact** (`contact.html`) – Contact details + enquiry form
- **Student Login** (`login.html`) – Demo login for learning portal
- **Dashboard** (`dashboard.html`) – Practice videos, audios & quizzes (placeholders)

## Tech

- Pure HTML + Tailwind CSS (CDN) + Font Awesome
- Fully responsive
- Client-side login demo (localStorage)
- Ready for static hosting (Vercel, Netlify, GitHub Pages)

## Deploy on Vercel

1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com) → New Project → Import the repository
3. Deploy (no build command needed; static files)

Or use Vercel CLI:

```bash
npm i -g vercel
vercel
```

## Local preview

Open any HTML file in a browser, or serve the folder:

```bash
npx serve .
```
